# Language icons

Local SVG assets from [flag-icons](https://github.com/lipis/flag-icons), MIT licensed. Source revision: `086f7e97d657358203916dbe84f61c2bccaa81eb`, downloaded October 2, 2026. Original license is preserved in LICENSE.txt.

Decorative icons supplement explicit language names. English uses the UK flag, Portuguese (Brazil) uses Brazil, and Arabic uses Saudi Arabia. Flags do not imply that a language is exclusive to one country. SVG images are served locally, independent of emoji fonts, and retain their shapes on Windows, macOS and mobile browsers.
